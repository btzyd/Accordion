# Accordion project page

Project page for **Accordion: Elastic-Depth Inference via Fixed-Prefix Layer Looping**.

Static site, no build step: `index.html`, `static/css/style.css`, `static/js/main.js`, and figures in `static/images/` (exported from the paper).
To preview locally, open `index.html` in a browser or run `python3 -m http.server`.

Deployed with GitHub Pages from the `main` branch, root folder.

The accordion icon is adapted from [Twemoji](https://github.com/twitter/twemoji) (CC BY 4.0, recolored); see `static/images/LICENSE-TWEMOJI`.
